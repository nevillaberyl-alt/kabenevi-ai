KABENEVI AI — PROJECT STARTER

1. Extract this ZIP file on your computer.
2. Open Visual Studio Code.

4. Open index.html to view or edit the prototype.

This is a front-end prototype only. Live AI chat, image/video generation, accounts, secure backend, and Play Store packaging are later development steps. Do not put private API keys in browser code.
